# Basic Cybersecurity Checklist

Use this checklist to improve personal and organisational security.

## Account Security

- [ ] Use strong, unique passwords.
- [ ] Enable multifactor authentication.
- [ ] Never share passwords or verification codes.
- [ ] Review account activity regularly.

## Device Security

- [ ] Install operating system and application updates.
- [ ] Enable firewall and antivirus protection.
- [ ] Lock devices when unattended.
- [ ] Back up important files regularly.

## Email and Internet Security

- [ ] Verify unexpected emails and sender addresses.
- [ ] Avoid suspicious links and attachments.
- [ ] Use trusted websites and secure connections.
- [ ] Report suspected phishing attempts.

## Data Protection

- [ ] Store confidential information securely.
- [ ] Restrict access to authorised users.
- [ ] Avoid sharing sensitive information through unapproved channels.
- [ ] Dispose of information securely when no longer needed.

## Incident Response

- [ ] Report suspected security incidents promptly.
- [ ] Record relevant incident details and times.
- [ ] Preserve evidence according to organisational procedures.
- [ ] Follow instructions from the IT security team.

## Conclusion

Review this checklist regularly and adapt it to your organisation's security policies.
